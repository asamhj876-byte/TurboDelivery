طريقة عمل APK من الموبايل فقط

1) ادخل على GitHub من Chrome وسجل دخولك.
2) اعمل New repository باسم TurboDelivery.
3) ارفع كل ملفات هذا المشروع إلى المستودع.
4) افتح تبويب Actions.
5) اختار Build Turbo Delivery APK.
6) اضغط Run workflow.
7) بعد انتهاء البناء افتح آخر عملية ناجحة.
8) من Artifacts حمل Turbo-Delivery-APK.
9) فك الضغط وستجد app-debug.apk.

لو GitHub طلب تفعيل Actions وافق عليه.

التطبيق مربوط بالموقع:
https://turbo.wuaze.com/index.php

ولا يحتاج قاعدة بيانات جديدة.
